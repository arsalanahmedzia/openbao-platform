First install failed: the operator pod hung in ContainerCreating:
  Warning FailedMount ... MountVolume.SetUp failed for volume "tls-secret" :
  secret "kube-prometheus-stack-admission" not found
Cause: admissionWebhooks.enabled=false removes the Job that creates that
Secret, but prometheusOperator.tls.enabled (default true) still mounts it.
Fix in Git: prometheusOperator.tls.enabled: false.
The fix only reached the cluster after the waiting reconcile of
apps-monitoring hit its 15 min timeout (wait: true); flux suspend/resume did
not end the waiting run. Then helm-controller's install attempt with the old
values timed out (10 min), and the next attempt used the new values.
