################################################################################

Decision: no prune protection; R07 accepted and documented (owner decision).
Nothing was changed in the cluster, so no test gate was needed.

Verified for the record: kustomize-controller v1.9.6 (the installed version,
clusters/demo/flux-system/gotk-components.yaml) documents the label or
annotation `kustomize.toolkit.fluxcd.io/prune: disabled` to exclude an object
from garbage collection, both when it disappears from Git and when its Flux
Kustomization is deleted. Deleting a Namespace still deletes everything in it,
so protecting the PostgreSQL Cluster alone would not protect its data.
